# Thor Bili 公开预览版

面向 AYN Thor 双屏掌机和 Android 11+ 手机的 B站客户端。包名为 `local.thor.bilichannels`，当前安装包面向 arm64 设备。

原作者：**fcl3469**。原项目：<https://github.com/fcl3469/thor-bilibili>。原项目代码和原创资源遵循根目录 `LICENSE`；第三方组件、模型和字典遵循各自许可证，见 `NOTICE`、`assets/THIRD-PARTY-NOTICES.txt` 与 `PHRASE-DICTIONARY.md`。

## 功能

- B站推荐、热门、专栏、动态、搜索、评论与播放历史；播放权限以平台及当前账号返回为准。
- Thor 双屏浏览与播放、手柄操作；普通手机支持横竖屏和全屏播放。
- 本地视频与磁力播放、下载及缓存管理。
- 迅雷云盘账号登录、目录浏览、日期排序、分页、清晰度选择、视频播放和续播历史。云盘文件名按账号返回内容显示。
- OpenGL／RIFE 插帧，效果与性能取决于设备及片源。
- 可选日语识别与中文翻译，模型由用户主动下载，校验后在本机运行；识别和翻译可能出错。
- 自愿打赏：支持微信、支付宝，提供 1／2／5／10 元和自定义金额；普通个人收款码需要在支付应用中填写金额，不影响任何 App 功能。

## 设备兼容性

开发过程中目前只在搭载 **骁龙 8 Gen 2** 和 **骁龙 8 Elite** 的设备上做过验证。**其他芯片尚未测试，兼容性、解码能力和插帧表现未知**，不承诺所有 Android 手机都能正常使用或达到相同帧率。

“支持手机版”说明 App 提供手机界面与操作方式，不代表所有手机芯片已经验证。插帧效果、帧率、HDR、字幕速度和持续运行情况取决于设备、系统及片源；请以具体版本的测试记录为准。

## 构建

需要 Python 3、Node.js、FFmpeg、CMake、Java 17、Android SDK（platform 35、build-tools 36.0.0）、Android NDK 和 Go。请设置 `ANDROID_SDK_ROOT`、`JAVA_HOME`、`ANDROID_NDK_HOME`，必要时设置 `THOR_GO`。依赖版本与哈希见根目录锁文件。

```sh
python3 fetch_deps.py
python3 build.py
python3 verify.py
```

首次构建需要下载第三方依赖。`fetch_deps.py` 会写依赖锁文件，构建前应核对其变化；已有锁定依赖可直接构建。本地构建会使用或创建 `.signing` 签名身份，该目录不可提交或分享。自行构建的签名通常不能直接覆盖官方发布包。
